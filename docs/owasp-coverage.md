# SecurityTest-AI: OWASP Top 10 Coverage & Detection Matrix

SecurityTest-AI features comprehensive coverage across the **OWASP Top 10 Web Application Security Risks**:

| OWASP ID | Category | Detection Mechanism | Agent Responsible |
| :--- | :--- | :--- | :--- |
| **A01:2021** | Broken Access Control | Missing authorization checks, path traversal probes (`../`), insecure direct object references. | `DASTAgent` & `SASTAgent` |
| **A02:2021** | Cryptographic Failures | Deprecated hashing algorithms (`md5`, `sha1`), plain text password/token handling. | `SASTAgent` |
| **A03:2021** | Injection | SQL Injection (raw queries, string formatting), OS Command Injection (`os.system`, `subprocess(shell=True)`), SSTI. | `SASTAgent` & `DASTAgent` |
| **A04:2021** | Insecure Design | Unrestricted file uploads, absence of rate limiting, insecure default credentials. | `SASTAgent` & `ExploitValidator` |
| **A05:2021** | Security Misconfiguration | Missing security headers (`HSTS`, `CSP`, `X-Frame-Options`), exposed debug modes (`debug=True`), exposed stack traces. | `ReconAgent` & `DASTAgent` |
| **A06:2021** | Vulnerable & Outdated Components | CVE checks against pinned packages in `requirements.txt`, outdated library dependencies. | `SASTAgent` (Dependency Tool) |
| **A07:2021** | Identification & Authentication Failures | Weak JWT secrets, missing session expiration, hardcoded credentials. | `SASTAgent` & `DASTAgent` |
| **A08:2021** | Software & Data Integrity Failures | Insecure deserialization (`pickle.loads`, `yaml.load(Loader=Loader)`), unsigned update downloads. | `SASTAgent` |
| **A09:2021** | Security Logging & Monitoring Failures | Sensitive data logged to console or logs, absence of audit trails for security actions. | `SASTAgent` |
| **A10:2021** | Server-Side Request Forgery (SSRF) | Unvalidated URL fetches, localhost/internal IP routing (`127.0.0.1`, `169.254.169.254`). | `DASTAgent` |

---

## Remediation Policy
Every identified vulnerability is linked with:
- **CWE Identification** (e.g. CWE-89, CWE-78, CWE-79)
- **CVSS v3.1 Vector** and Base Score
- **Actionable Remediation Code Diff** generated by `RemediationAgent`.
